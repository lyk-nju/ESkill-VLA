# 官方 LIBERO-40 字段自查

对照 [docs/data.md](../../../../docs/data.md)。下表区分官方 HDF5 原有字段与本轮结合 AtomicVLA 后生成的内容，人工验收仍待完成。

| 我们需要什么 | 有没有 | 备注 |
| --- | --- | --- |
| RGB 图像 | 有 | `obs/agentview_rgb` 等；官方主相机为 128×128，当前 RLDS 为 256×256，不能直接当作同一批像素。 |
| 任务指令 | 有 | 任务文件／BDDL 中有完整任务描述。 |
| 机器人状态 | 有 | `states`、`obs/joint_states`、`obs/gripper_states`、`obs/ee_states`；单臂 Panda。 |
| 机器人动作与运动记录 | 部分 | `actions` 为 7 维控制记录，末端可从状态恢复；动作缩放与控制时序需结合来源配置解释。 |
| 每臂 Event 边界 | 无 | 官方 HDF5 没有；本轮沿用 AtomicVLA 的分段及其源帧映射。 |
| 子事件描述与技能标签 | 无 | 官方 HDF5 没有；本轮沿用 AtomicVLA 标签，保留重叠／技能冲突。 |
| 执行器视觉区域 | 部分 | 没有现成框；已按源关节恢复夹爪并独立渲染完整屏内 mask／bbox。 |
| 当前对象视觉区域 | 部分 | `states`＋场景实体支持原生渲染；操作对象仍需规则绑定，框与 RLDS 原图的贴合待人工核验。 |
| Event 终点对象区域 | 部分 | 绑定后读取同一对象在适配后 Event 终点的框；无需独立补标。 |
| 时间与同步信息 | 部分 | 有行号、完整动作和状态；本轮保存精确行映射，重放版本仍有状态偏差，10 fps 仅为展示帧率。 |
| 坐标与相机信息 | 部分 | `model_file` XML＋仿真配置可恢复相机／几何／末端；本轮核对关节顺序和显式相机参数，不能据此宣称整份模型完全等同。 |

来源和检查入口见 [README](../README.md)；逐轨迹记录见 [alignment.csv](alignment.csv)。本轮未运行 VLM 或 SAM 补框。
