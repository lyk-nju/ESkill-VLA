# 先计算可行落点，再进行 Copy-Paste

2026-11-18，technical 数据检查，不训练模型。此页为均匀选择 Copy 候选的记录；后续原任务目标优先配置见[80%／20% 采样](../copy_target_bias/README.md)。

流程为：抽取一个可移动物体 → 检查原位置擦除区 → 计算可行落点图 → 从可行位置均匀采样一个 → 更新像素、框和标签。其他实体 bbox 与机器人 mask 组成占用图；积分图一次求出能容纳完整目标矩形的空位，同时限制屏内、位移至少 4 源像素、每轴不超过图宽／高 30%。地图标记的是**矩形左上角坐标**，不是完整物体可以覆盖的像素集合。范围和物体尺寸均使用源图坐标。

没有可用落点就保留原图，不随机反复试位、不在线分割或重渲染；原位置的每边 2 px 擦除保护仍保留。此图只表示二维区域约束，不引入三维场景规划。`valid_destination_count` 记录有效坐标数量，失败原因区分源区实体／机器人冲突与确实没有可用落点。

## 相同 8,000 帧对比

沿用三类候选规则与相同的 40 任务×200 训练帧、seed／epoch／draw，仅替换 Copy 函数。旧函数来自 `0e2017b`，旧函数每帧使用原 RNG 状态的独立副本，新函数使用正式增强 RNG；两者交替先运行以减小缓存顺序影响。样本身份、旧 Copy 成功数和文本替换次数均核对一致。

| 指标 | 随机试一个位移 | 可行落点采样 |
| --- | --- | --- |
| Copy 尝试 | 2,129 | 2,129 |
| Copy 成功 | 551／8,000，6.89% | 1,398／8,000，17.48% |
| 尝试后的成功率 | 25.9% | 65.7% |
| 实际监督目标移动 | 62／8,000，0.78% | 169／8,000，2.11% |
| 反事实文本替换 | 1,210 | 1,210 |
| 增强新造成完全遮挡 | 0 | 0 |

最终本批次有 297 次原位置与其他实体框冲突、51 次原位置与机器人区域冲突、383 次没有可移动候选；没有“可计算到合法空位却随机落到非法位置”的失败，也没有无可用落点的样本。空间任务保护与 50% 概率未触发的样本仍按原约定跳过。

Copy 函数 CPU 耗时（包括其 mask 读取回调与实际粘贴，不包括 Dataset 其他步骤、模型、GPU）：

| 项目 | 旧函数 | 新函数 |
| --- | --- | --- |
| 全部 8,000 次调用平均 | 0.086 ms | 1.161 ms |
| 全部调用 P95 | 0.265 ms | 7.242 ms |
| 仅触发 Copy 的调用平均 | 0.315 ms | 4.351 ms |

平均每样本新增约 1.074 ms；其中也包含成功粘贴次数增加带来的工作量，不全是可行图计算。此测量不能直接换算为完整训练单步耗时。
