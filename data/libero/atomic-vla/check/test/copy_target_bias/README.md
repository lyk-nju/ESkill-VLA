# 原任务目标优先的 Copy-Paste

2026-11-18，`feat/visual-primitive-v3`。本轮只调整数据采样，不训练模型。此页为取消容器黑名单前的记录；最新规则及检查见[取消容器黑名单](../copy_no_blacklist/README.md)。

用户确认：`copy_target_prob=0.8`、`target_swap_prob=0.2`；Copy 触发概率仍为 0.5。

原目标指当前 Event 的 `interaction_target`：Pick 通常是物体，Place 通常是容器。触发 Copy 后，若原目标具备 Copy 资格、源区安全且存在合法落点，给它 80% 的选择概率，其余候选平分 20%。原目标不可 Copy 时排除它，其他候选均匀选择。只有原目标一个可用候选时直接选它。原目标预案缓存复用，最多规划原目标和一个其他候选，不循环尝试全部物体。

仍使用“先算可行落点，再采样”；完整任务反事实只在有合格候选时按 20% 概率触发。Copy 权重依赖原 Event 目标，和反事实文本抽样使用独立 RNG。最终监督目标可能被文本替换，所以区分 `copied_task_target` 与 `target_moved`。

## 同一批 8,000 帧

40 任务各 200 个训练帧，沿用原 seed／epoch／draw；不是全量比例。控制组使用[均匀 Copy 的原检查](../copy_placement/README.md)，新规则分别运行反事实概率 50% 和 20%。两组新规则的 Copy 对象、位置和成功状态逐帧完全相同，只有文本抽样变化。

| 配方 | 原任务目标作为监督且移动 | 反事实目标作为监督且移动 | 移动监督合计 |
| --- | ---: | ---: | ---: |
| 均匀 Copy＋50% 文本替换 | 43 | 126 | 169 |
| 80% 原目标优先＋50% 文本替换 | 91 | 125 | 216 |
| **80% 原目标优先＋20% 文本替换** | **117** | **50** | **167** |

最终原任务目标的移动监督为原来的 2.72 倍；原任务文本保留 7,546／8,000 帧，反事实替换 454 帧。Copy 成功数从 1,398 增至 1,427。**整体移动监督为 167／8,000（2.09%），与旧配方 169／8,000（2.11%）基本持平，不能宣称总移动率提高。** 本轮把监督更多分配给原任务目标，减少了反事实目标的移动监督。

触发 Copy 的 2,129 帧里，原目标真正可安全移动的只有 150 帧；其中 139 帧还有其他候选，原目标被选择 116 次（83.5%，有限样本下的实测值），另外 11 帧只有原目标候选。80% 是条件概率，不是全部帧的移动率。现阶段总体上限受到原目标的可移动机会限制，例如目标为容器、已处于夹爪交互区或原位置不可安全擦除。若后续要提高总移动率，应另行研究可移动原目标帧的采样，不能仅凭调高此概率保证提升。
