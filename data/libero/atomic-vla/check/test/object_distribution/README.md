# LIBERO40 物品在主相机中的分布

覆盖全部 40 任务、1,693 条轨迹，每条等距抽取起点、终点及中间三帧，共 8,465 帧。统计所有场景物品和有限固定装置，28 个资产类别；部件、桌面、地面和背景装饰不另外计入。

已提取 10,978 条实例轨迹对应的 54,890 组框，采样点均有有效完整屏内框。与原密集标注重合的 7,701 组 bbox 逐值一致；源 Episode 元数据哈希保持原值。提取按任务隔离 MuJoCo 进程，早期共享上下文产生的错误结果已排除。

这批数据呈现明显的位置簇：篮子中心主要在左侧，小烤碗与饼干分别长期集中在约 (72,127) 和 (117,188)，收纳盒几乎固定在 (170.5,117.5)。黑碗跨21个任务的位置范围更广。28类中20类的“同任务初始中心 P5–P95 跨度”的跨任务中位数，x／y均不超过10 px；牛奶约2.2×1.5 px。类别跨场景出现在多个位置，不代表每个任务内的初态变化充分。

食品框的尺度也较小：黄油中位14×18 px、巧克力布丁16×18 px、牛奶19×41 px。以上是数据分布现象，不能单独证明模型依赖位置捷径。

坐标以源主相机 256×256 图像为准，左上角 (0,0)，向右／下增加。bbox 沿用忽略遮挡的完整屏内区域；一个像素的覆盖频率按该类的实例—帧样本归一化。中心的 P5–P95 对 x、y 分别统计，不能解读为联合 90% 覆盖。每个实例、每个采样帧权重相同，未按任务均衡。

同时报告同一任务内的初始中心跨度，用来区分场景内摆放变化与跨任务布局变化。五帧采样不能保证捕捉运动过程的全部极值；本结果用于检查数据位置偏置，不作为未见布局泛化效果。
