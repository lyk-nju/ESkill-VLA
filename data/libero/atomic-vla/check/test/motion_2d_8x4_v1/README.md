# 八点二维 Motion 核验

每臂 8 个 256 维 Motion tokens，逐 token 共享 MLP 解码主相机归一化二维末端坐标；偏移为 `[4,8,12,16,20,24,28,32]` 个来源帧，末尾 `hold_last`。Grounding 每角色 16 个 tokens，数量独立。

- [保存／渲染报告](report.json) · [Dataset 核对](verification.json) · [CPU 小模型训练／恢复／推理检查](smoke/report.json)
- [人工核验表](manual_review.csv)：pending，待人工检查。

Dataset 与保存标签逐帧比较最大误差为 0。共 16,184 个有效点，其中 14,744 个来自真实未来记录、1,440 个为终点保持；2,298 个真实未来点跨 Event。末帧无效、屏外、内部缺帧及不存在臂的处理由自动测试覆盖。

视频显示真实标签，非模型预测；白色十字是当前末端，八个彩色点是未来位置，白色圆圈／END 是末尾保持点。蓝框为夹爪、绿框为当前对象、黄框为 Event 终点对象。10 fps 只用于展示。

相机几何复用已核验的六点试验逐帧投影及标定，检查了来源与数组 SHA256，没有重跑原生渲染。新八点重新采样、保存、回读、渲染，并完整解码核对 2023 帧与十个章节。原生 marker 误差上限 0.2191 px 为继承证据。

自动测试共 189 项通过（首轮 183 通过；受本机 socket／缓存权限影响的项目在修正运行环境后复核通过）。CPU smoke 使用真实十条数据、256 维辅助模块、8 个 Motion／每角色 16 个 Grounding tokens，执行两步训练、一步恢复及策略推理；骨干与 VAE 是随机小模型，仅验证工程链路。没有启动四卡正式训练，也未验证闭环成功率。

Motion 训练接口已完成。全量 1,693 条的相机标定仍需后续导出，当前正式索引不能直接提供有效二维 Motion 标签。Grounding 的 FLUX 潜变量回归仍待独立迁移；当前检查保留旧视觉去噪分支。

运行方法与检查配置见 [LIBERO 示例](../../../../../../examples/libero/README.md#八点二维-motion)。
