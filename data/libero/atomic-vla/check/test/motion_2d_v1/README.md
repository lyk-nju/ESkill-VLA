静止参照把当前 EEF 位置复制到六个未来时刻，仅用于后续比较预测误差，不是模型结果。投影使用源 RLDS 的 `gripper0_grip_site` 世界坐标，结合原生相机几何；原有官方回放状态对齐警示继续保留，不以回放 EEF 替换源 EEF。遮挡不取消监督，出画／相机后方点才无效。本批未出现出画点，这类边界另有数值测试。

`episodes/<annotation_id>/motion.npz` 保存逐帧像素点、有效性、六点源帧索引、六点像素与归一化坐标、跨 Event 标记；同目录 `motion.json` 保存来源、标定和检查值，`native_*.png` 是三帧原生参考图，`preview.jpg` 为完整渲染器预览。视频完全回读这些保存结果生成。该侧车采用 `eskill.motion2d.v1-pilot`，未重写正式 Episode schema。

实现：[motion_2d.py](../../../../../../scripts/preprocess/libero/atomic_vla/motion_2d.py)。纯数值投影、图像几何与固定来源步采样位于 [transforms.py](../../../../../../src/openpi/transforms.py)，Dataset 不依赖仿真器。渲染复用现有 LIBERO 布局，增加试点专用二维面板。

验证：`test_motion_2d.py`、`test_libero_render.py`、`test_training_data.py`、`test_episode_dataset.py` 共 43 项通过。覆盖非方形 letterbox、像素中心、背向／出画点、缺帧、末尾、静止位置，以及原有读取／渲染行为。查看视频后，可在 [manual_review.csv](manual_review.csv) 记录投影和未来窗口是否合适。
