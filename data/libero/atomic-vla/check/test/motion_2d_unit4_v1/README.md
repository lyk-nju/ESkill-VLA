# 四帧时间单位：未来二维末端轨迹

2026-11-02：每个时间单位改为 **4 个来源帧**，六个偏移从 `[2,4,5,7,9,10]` 扩为 **`[8,16,20,28,36,40]` 帧**。来源步仍是发布版 no-noop RLDS 的记录索引，不解释成秒数。原始观测、动作和采样锚点均逐帧保留。

[十条合并视频](../video/motion_2d_unit4_v1/merged10_motion_2d.mp4) · [单条视频与章节](index.html) · [同帧新旧对照](comparison.jpg) · [完整报告](report.json)

使用与 [首轮](../motion_2d_v1/README.md) 相同的十条轨迹，共 2,023 帧，合并视频 202.3 秒。白色十字是当前末端，六个彩色点是未来真值；左下表格显示实际来源帧偏移。图中的线只连接六个采样点，完整运动可能在点间弯曲。

| 项目 | 一帧单位 | 四帧单位 |
| --- | --- | --- |
| 最远未来点 | +10 帧 | +40 帧 |
| 全部六点的有效比例 | 96.95% | 87.81% |
| 最远点有效比例 | 95.06% | 80.23% |
| 跨 Event 的有效点数 | 592 | 2,345 |
| 最远点静止预测参照误差 | 14.89 px | 46.35 px |

误差单位为 224×224 模型画布像素；静止参照直接使用当前末端位置，不是模型预测。新版共有 10,658 个有效点，缺少的 1,480 个点均为 Episode 尾部没有相应未来记录，逐点 mask，不复制最后位置。当前对象 Goal 仍取当前 Event 终点，跨 Event 的运动点正常保留。

复用首轮已核验的逐帧投影，重新采样后保存，再从保存标签渲染；本轮没有重跑仿真或 GPU。每条 `motion.json` 的 `projection_source` 记录前一版元数据与数组的 SHA256，原生检查结果明确继承首轮。新旧逐帧位置、有效性与相机参数一致，旧视频与旧标签保留。

每条标签在 `episodes/<id>/motion.json` 与 `motion.npz`；参数显式记录 `time_unit_source_frames=4`、`offset_units` 与实际 `offsets`。`manifest.json` 保存本轮代码和来源依据。视频全帧解码、连续时间与十个章节检查通过；13 项投影／渲染回归测试通过。模型训练尚未切换到二维 Motion，用户人工验收 pending。

复现入口见 [LIBERO 示例](../../../../../../examples/libero/README.md#二维未来末端监督试点)，新增参数为 `--time-unit-frames 4 --reuse-projection .../motion_2d_v1`。
