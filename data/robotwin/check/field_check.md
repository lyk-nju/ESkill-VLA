# RoboTwin clean 字段自查

对照 [docs/data.md](../../../docs/data.md)。范围为当前 clean 50×50 原始数据，依据已有采集记录、十条固定核验样本与采集代码整理；本次目录清理未重新逐帧审计。来源与结果见 [collection.md](collection.md)、[summary.json](summary.json)。

| 我们需要什么 | 有没有 | 备注 |
| --- | --- | --- |
| RGB 图像 | 有 | 主相机、双腕及完整源终点；按源行读取。 |
| 任务指令 | 有 | 保存任务指令与语言变体。 |
| 机器人状态 | 有 | 双臂手臂实测 qpos 与驱动目标分开；夹爪字段为命令，不冒充实测开度。 |
| 机器人动作与运动记录 | 部分 | 有逐物理步控制命令、与 RGB 的对应和双臂末端位姿；π0.5 动作表示及训练对齐契约待确定。 |
| 每臂 Event 边界 | 部分 | 保存带 arm、实例与起止的源原语；正式语义 Event／Hold／Idle 尚未全量整理。 |
| 子事件描述与技能标签 | 部分 | 有原语与阶段，六任务曾做候选映射；共享词表、逐事件语义与有效性尚未冻结。 |
| 执行器视觉区域 | 有 | 主相机原生可见区域及忽略外部遮挡的完整屏内夹爪区域；腕部不要求区域标注。 |
| 当前对象视觉区域 | 部分 | 有逐实例可见 mask／bbox；还需完整屏内区域与每臂 Event 的操作对象关联。 |
| Event 终点对象区域 | 部分 | 源终点 RGB／实例区域保留；须先确定语义 Event、同一操作对象及完整区域，再按终点查询。 |
| 时间与同步信息 | 有 | 保存真实物理步、时间和控制→RGB 行映射；保留同刻源行，不用标称播放 fps 推算时间。 |
| 坐标与相机信息 | 部分 | 有相机内外参和世界系末端位姿；末端参考点、单位与公共接口元数据仍需明确整理。 |

统一训练接口尚未导出；采集结构通过不自动表示语义标签与人工验收通过。
