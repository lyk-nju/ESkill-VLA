# RoboTwin 字段初查

对照 [docs/data.md](../../../docs/data.md)。范围：本地 event_data 的 10 条已有轨迹；有字段不代表语义和质量已验收。

| 我们需要什么 | 有没有 | 备注 |
| --- | --- | --- |
| RGB 图像 | 有 | 主视角、双腕及第三视角；HDF5 未保留原序列最后一帧。 |
| 任务指令 | 有 | instructions 中有任务文本。 |
| 机器人状态 | 部分 | 有关节／夹爪及末端位姿；当前采集 getter 的关节值为驱动目标，非实测 qpos，历史版本需回查。 |
| 机器人动作与运动记录 | 部分 | 有后移一帧的关节目标序列及双臂末端路径；需明确状态契约与末端参考点。 |
| 每臂 Event 边界 | 部分 | subtasks 有 arm 和起止帧；从原始区间整理语义 Event／hold，不能只用全局筛选后的稀疏边界。 |
| 子事件描述与技能标签 | 部分 | 有 grasp、place、lift 等原始标签；共享技能词表及区间映射待定。 |
| 执行器视觉区域 | 无 | 所读 HDF5 无区域；可评估原生 link 分割，缺失时再考虑检测／分割。 |
| 当前对象视觉区域 | 无 | 所读 HDF5 无区域；可评估实例分割及对象追踪。 |
| Event 终点对象区域 | 无 | 补齐对象区域后取结束帧；同时解决终点 RGB 对齐。 |
| 时间与同步信息 | 部分 | 有事件帧号、时间和 15 Hz；终点及视频／HDF5 映射需核验。 |
| 坐标与相机信息 | 部分 | 有相机内外参和末端位姿；矩阵约定、坐标系与参考点需落实。 |

当前代码与全量事件记录的进一步检查见 [旧管线核对](../pipeline_review.md)；按臂接触归属和命令／测量语义尚未人工验收。
