# CLAP：动作锚定与人类视频教师

**用途：补充机制，按需阅读。** 本卡解释来源，不增加实施要求；当前方法见 [方向文档](../../docs/action_representation.md)，实现以 [design.md](../../docs/design.md) 为准。

## 原工作机制

Act-VAE 用真实机器人动作建立并冻结码本；视觉分为动作与环境两路。机器人对比正例来自配对动作，人类 v2 正例来自干净帧对的 EMA teacher。

## 对本项目的参考价值

保留“机器人动作锚定共享运动”与“人类视频自监督”使用不同监督来源的思路，帮助界定未来跨本体数据条件。

## 采用边界

当前不增加动作码本或 EMA 对比训练。v1 的自对比描述与 v2 不同；无机器人控制标签的人类视频也不意味着全流程无监督。
