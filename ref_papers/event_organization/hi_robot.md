## 论文实际做了什么

高层 VLM 从当前画面和复杂指令产生简单指令，低层 π0 根据简单指令、画面与状态生成动作。高层每秒或收到新反馈时更新。训练将示范整理为短技能，并利用图像、技能及合成对话扩展高层监督。

这里的层次不是“等事件成功检测器确认才切换”，也不是学习无动作视频运动表征。简单指令可以同时包含行为与对象，不能直接当作已分离的 atomic skill。

## 对本项目的判断

Hi Robot 说明任务组织、指令语义和低层执行可以分别训练。对我们的启发是：Event 的离线组织不必决定唯一在线更新规则，固定时间重规划也是完整而合理的基线。因此 Phase 1 不必为 Event 定义立即加入新的外部完成判定模块。

与此同时，使用 π 系列加一个高层语义接口已是明确的现有路线。如果 atomic skill / target grounding 的贡献只表现为生成更容易执行的子指令，需要与这种整体子指令方式比较，而不能只与不带任何中间监督的端到端模型比较。

项目中的 atomic skill / target grounding 并行设计提供了更具体的可检验内容：同一技能换对象时 atomic skill 应稳定，target grounding 应改变；同一对象切换交互时 atomic skill 应改变，target grounding 的相关部位可能改变。这比“有高层规划”更有辨识度，但也需要比整体子指令更多的标注与评估预算。

## 最小验证与证伪条件

同一任务集合、主干、示范量下，比较整体子指令条件与 atomic skill / target grounding 分离条件。为整体子指令也提供相同对象和空间信息，避免让对照因缺信息而天然较弱。

分别记录组合成功率、错误对象交互、重复执行已完成步骤、受到用户指令变化后的恢复。控制更新频率与观察历史，再看因子分工的收益。若等预算整体语言接口达到相同效果，应把 atomic skill / target grounding 的价值转向可解释诊断或更强分布外稳定性，不能只依据辅助分类精度宣称优势。

**后续核查**：训练子指令在任务间的复用程度；合成高层监督的成本；双臂并行动作是否适合单条简单指令。
