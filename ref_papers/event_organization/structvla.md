## 论文实际做了什么

离线结合夹爪变化、平滑速度信号、间隔约束和 VLM 筛选获得结构化关键帧。第一阶段学习稀疏未来帧序列；第二阶段转为 FAST 动作 token 学习，输入语言及交错的观测/动作历史，损失仅施加于动作 token。离线筛选 VLM 不进入部署。

这些帧是交互里程碑，未必等价于完整的 pick/place 语义区间。也不能将其概括为“部署时必须先生成未来帧，再调用独立控制器”。结构知识可以经过训练迁移到动作预测。

## 对本项目的判断

最值得借鉴的是把两个问题分开：训练数据应保留哪些有用状态，以及策略在推理时是否必须显式维护 Event。我们目前的 Event 组织未必需要增加完成检测器；本工作为“用结构训练模型、让权重吸收结构”的路线提供了具体相关设计。

它也挑战了将 Event 粒度完全绑定动词的做法。接触前的对齐、稳定抓持后的抬升，都可能是控制上关键的点，但只属于同一个语义 atomic skill。如果所有关键帧都强制产生新 atomic skill，可能把运动过程重新编码进技能词表。建议保留两套标签：稀疏物理里程碑与较粗的语义事件，并允许二者多对一。

本项目更有辨识度的问题仍是：atomic skill 的跨对象不变性，以及与 atomic skill 并行的当前空间 target grounding，是否比一般未来结构预训练提供额外收益。看到结构未来有效，不能直接推出 atomic skill / target grounding 的分工有效。

## 最小验证与证伪条件

固定 π0.5 主干、动作样本与训练预算，对比：直接动作微调；关键帧预训练后动作微调；只有 Event/atomic skill / target grounding 辅助目标；两者结合。关键帧数量、历史长度也需要配平。

再用语义边界与物理里程碑生成等量训练目标，分别评估未见技能组合、同技能换对象、接触前精细对齐。若物理里程碑已解释全部增益，便应缩小“语义 Event 必要”的主张；若组合收益只在显式 atomic skill / target grounding 下出现，才能支持因子化接口。

**后续核查**：完整消融中结构筛选、预训练数据与历史上下文各贡献多少；关键帧序列是否覆盖双臂并发；公开实现与论文第二阶段接口是否一致。
