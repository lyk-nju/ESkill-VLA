## 论文实际做了什么

从低层策略已有训练片段检索近邻，以首尾视觉表征及持续时间相似度评分，动态规划选择示范分段，再用分段语言监督微调高层 planner。低层执行器同时接收观测、状态、总任务和子任务。OOD 扩展可结合 UVD 类分段线索。主要评估筛选了低层使用专家 planner 时表现较好的任务，附录提供更完整范围。

该设置使用目标任务示范微调 planner，不能直接称为无需更新的组合零样本泛化。相似度高也不自动证明片段具有相同因果交互机制。

## 对本项目的判断

RDD 提供一个比“边界标得像不像人类”更强的问题：分出来的 Event 是否处于动作模型的可执行分布中？如果把 pick 切到刚闭合夹爪，下一事件从不稳定抓持开始，语言上看似整齐，低层却可能没有这种初始状态的经验。

我们的 atomic skill 词表因此不能只通过文本聚类定义，还应记录进入条件、结束效果及执行成功率。但这不要求把对象身份塞进 atomic skill；可以用独立的条件覆盖统计评估同一 atomic skill 在不同 target grounding 下是否可实现。

此工作也提醒分段可能依赖既有执行器。如果对每个 backbone 都产生不同边界，就很难声称存在唯一“正确”的原子粒度。更稳妥的主张是找到跨任务复用与执行可靠性之间的合适粒度，并报告它随策略能力变化的范围。

## 最小验证与证伪条件

固定同一低层策略及训练库，比较语义脚本边界、夹爪边界、视觉边界和训练支持度驱动的边界。对每段从多个扰动起点执行，记录完成率与进入条件覆盖率，再看离线边界指标能否预测它们。

组合测试必须分开“无目标任务微调”和“给定少量目标任务示范后适配”。若方法优势只发生在后者，应将结论限定为高层对齐与适配；若检索仅匹配背景，换背景后相似度下降也会暴露伪共享。

**后续核查**：持续时间惩罚对变速示范的偏置；双臂并发时单一首尾嵌入是否够用；与语义 atomic skill 约束共同优化是否会牺牲执行覆盖。
