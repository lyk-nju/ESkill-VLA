# AtomSkill：事件边界与技能语义

**用途：当前方法参考。** 本卡解释来源，不增加实施要求；当前方法见 [方向文档](../../docs/event_organization.md)，实现以 [design.md](../../docs/design.md) 为准。

## 原工作机制

以夹爪状态变化形成候选分段，由 VLM 提供技能语义；重采样事件动作，经 VQ 编码和语义／时间对比训练形成技能表示，策略结合技能先验、keypose 与动作预测。语义正对还要求相同量化 token。

## 对本项目的参考价值

提供 Event 边界与技能语义分别组织的依据。一个 Event 对应一次 Skill 执行，同一 Skill 类型可跨 Event 复用；当前采用脚本／状态记录得到可核验标签。

## 采用边界

原论文技能码包含运动信息；ESkill-VLA 的冻结文本原型分类与独立可训练技能表是自己的设计。夹爪变化只是分段线索，不等于接触成功；原文 keypose 收益也非所有任务组一致。
