# Knowing When to Stop：把执行时长与语义事件边界分开

> **当前定位（2026-10-28）：补充 · 按需补充与替代路线。** 作为替代分段、进度或组合评测的按需参考；当前先落实可核验事件边界与监督接口。 以 [当前清单](../catalog.json) 与 [方法文档](../../docs/event_organization.md) 为准。

> 以下保留此前原文阅读与推论；其中“核心／优先实现／本轮”等表述属于记录时的判断，不替代上述当前定位。

**论文**：Knowing When to Stop: Adaptive Action Chunking via Internal Cross-Attention Dynamics in VLAs；Runze Xu 等；arXiv:2609.00908。v1 为 2026-09-01；本轮读 v3（2026-09-16）。[原始记录](https://arxiv.org/abs/2609.00908) · [原文](https://arxiv.org/html/2609.00908v3)。阅读：§II-B、§III、§IV 对照；未复现。

**为何补入核心。** 这是执行长度的核心控制实验，不是语义 Event 发现方法。它能直接检验“变长执行有效”是否足以支持“语义分段必要”。

**原方法的必要事实。** 从动作对 VLM 的 cross-attention 计算熵，寻找持续的高熵平台，截取本次执行前缀；不重新训练或额外采样。§II-B 对比 AAC 的多次采样不确定性估计，§III 仅将熵与动作误差联系为经验代理。

**对项目的判断。** 训练组织的 Event、预测动作块长度和本次执行长度是三个变量。即使训练固定长度，执行仍可自适应；即使训练按语义事件，遇到高不确定性也可能需要提前重新观察。将两者设为同一个边界，会让我们无法判断收益来自语义共享还是闭环刷新。

建议在同一 π0.5 checkpoint 上比较固定执行长度、长度分布匹配的随机刷新、此类内部统计刷新；再在相同三种规则下比较有无 Event 辅助监督。固定平均推理调用预算，同时报告成功率、接触失败、动作不连续与时延。若 Event 收益在等刷新预算后消失，应优先修正归因。

**限制。** 高熵不是真实成功/失败标签；可行动作多模态、视角变化或 token 数变化均可能影响统计。论文结果也并非所有单任务都优于所有固定长度，不能写成普遍支配。复现时需核验读取注意力权重对实际 attention 后端与时延的影响。
