## 论文实际做了什么

在 π0.5 上增加两个 query token：分类 motion/skill 二元阶段，预测下一夹爪变化处或终态的关节关键帧。阶段标签由扩展边界后的夹爪闭合区间生成；联合动作流匹配、阶段分类和关键帧回归训练。推理保留 query token，但不调用辅助预测头。

二元阶段不是语义 atomic skill，未来关节目标也不是当前视觉 target grounding。夹爪闭合是实用启发式，不能直接当作所有任务的物理接触真值。

## 对本项目的判断

这是一条需要优先精读并尽量实现的近邻基线：它与我们“保留 π0.5 主干、增加轻量结构监督”的 Phase 1 设想非常接近。因此新增辅助头本身不足以构成方法辨识度，应围绕语义不变性、当前目标定位与条件动作多样性提出更具体的问题。

此工作也可能提供成本更低的起点。倘若夹爪与关节状态已经包含足够的事件线索，复杂语义标注的边际价值需要通过组合泛化体现。若只测训练分布成功率，容易把普通正则化收益误读为 Event/atomic skill / target grounding 分工成立。

值得做一个明确的失败集：张开夹爪推动物体、空夹爪闭合、持续闭合过程中连续完成多个不同交互、双臂不同步事件。这里不是断言论文在这些任务失败，而是检验夹爪启发式何时不足、语义和空间监督是否真的补上缺口。

## 最小验证与证伪条件

固定训练量、query 数和辅助损失总权重，对比 π0.5、StaKe 类二元阶段/关节目标、语义 atomic skill/当前 target grounding、两者组合。对语义方案报告标签生成与人工核验成本；不要通过给对照更少参数或更低监督预算放大收益。

先检验错误对象交互、接触位置、无夹爪转换任务及未见 atomic skill 组合。如果 atomic skill / target grounding 只在有夹爪变化的常见任务上提升而不能改善这些诊断集，便需重新检查所谓语义收益是否只是复制了夹爪阶段信息。

**后续核查**：完整消融中的 query 与标签贡献；损失权重敏感性；关节关键帧对不同机器人结构的依赖；保持 query 但去掉辅助头的具体运行开销。
