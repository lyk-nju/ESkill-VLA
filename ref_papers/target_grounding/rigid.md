# RIGID：对齐空间关系是否比对齐特征更稳

> **当前定位（2026-10-28）：补充 · 按需补充与替代路线。** 作为几何、功能区域或行为诊断的补充；当前主线是三视觉锚点的局部去噪监督。 以 [当前清单](../catalog.json) 与 [方法文档](../../docs/target_grounding.md) 为准。

> 以下保留此前原文阅读与推论；其中“核心／优先实现／本轮”等表述属于记录时的判断，不替代上述当前定位。

**原文：** Relational Spatial Alignment for Vision-Language-Action Models；arXiv 2610.24705，v1 2026-10-17。[版本](https://arxiv.org/abs/2610.24705) · [§2–3、附录 B](https://arxiv.org/html/2610.24705v1)

RIGID 比较直接几何特征对齐，改为视图内/跨视图关系分布的几何感知传输对齐；明确引用 RKD。其旋转不变性针对 latent 特征坐标基，不是物理相机或场景旋转保证。秩分析也不构成所有表征坍缩问题的普遍定理。

**对项目的意义。** target grounding 可能既需要局部几何，也要保留行为和语言语义。新增几何 loss 后不能只查 depth probe；还应检查对象替换、同义指令、关系组合和行为模板是否退化。关系蒸馏提供一种对照，未证明必须采用复杂 OT。

**最小比较。** 保持教师、token 层、数据、优化预算相同，比较直接特征 loss、关系 loss、ROI 重建。报告动作成功、局部几何误差、语言目标选择和特征谱；不要用谱更平直接替代泛化结果。

本轮读 §2、3.1–3.2 与附录 B。其 related work 对 ReconVLA 的“显式 3D 重建”归类与 ReconVLA 原文不符，笔记不采用。返回 [机制链](evidence.md#trace)。
