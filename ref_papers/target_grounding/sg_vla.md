# SG-VLA：当前空间监督与分阶段梯度介入

> **当前定位（2026-10-28）：补充 · 按需补充与替代路线。** 作为几何、功能区域或行为诊断的补充；当前主线是三视觉锚点的局部去噪监督。 以 [当前清单](../catalog.json) 与 [方法文档](../../docs/target_grounding.md) 为准。

> 以下保留此前原文阅读与推论；其中“核心／优先实现／本轮”等表述属于记录时的判断，不替代上述当前定位。

**原文：** *SG-VLA: Learning Spatially-Grounded Vision-Language-Action Models for Mobile Manipulation*，arXiv 2603.22760。v1/本轮阅读版本：2026-03-24。[版本记录](https://arxiv.org/abs/2603.22760) · [原文 §4–5](https://arxiv.org/html/2603.22760v1)。

**机制证据。** 多视角 RGB-depth 的辅助目标包括对象 pose、mask、机器人状态和二元抓取状态；后者不是接触图或未来抓取位姿。§5.2 先阻断辅助 decoder→VLM 的梯度，但允许动作预测更新 VLM，随后联合训练。§5.3 的可选 flow head 阶段冻结整个 VLM，以稳定输入特征。

**和项目的关系。** 显式空间监督不只有局部 RGB 重建这一条路线。对象角色、相对几何和当前抓取状态可以成为更小的监督目标；是否足够支撑本项目的精细交互，需要任务层面的验证。该文的阶段安排可作为训练稳定性的候选，而不是证明所有 action representation 学习都必须冻结骨干。

**建议比较。** 同一标签预算下比较 ROI 重建与当前空间目标；同一结构下比较辅助头先训练后联合更新与从头联合更新。评测应区分“可解码对象位置”与“目标位置变化导致正确动作变化”。控制深度输入、可训练参数、阶段训练步数及对象位姿标签的获得成本，再判断增益来源。

**阅读边界。** 本轮读 v1 §4.1–4.3、§5.1–5.3 及相关表格；未运行代码。结论局限于其移动操作与 RGB-depth 设置。与本项目的联系是不同监督及训练日程的对照，未核实与其他项目卡之间的直接继承关系。
