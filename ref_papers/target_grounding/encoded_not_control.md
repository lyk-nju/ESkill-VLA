# Encoded but Not in Control：知道目标与按照目标行动分开测

> **当前定位（2026-10-28）：补充 · 按需补充与替代路线。** 作为几何、功能区域或行为诊断的补充；当前主线是三视觉锚点的局部去噪监督。 以 [当前清单](../catalog.json) 与 [方法文档](../../docs/target_grounding.md) 为准。

> 以下保留此前原文阅读与推论；其中“核心／优先实现／本轮”等表述属于记录时的判断，不替代上述当前定位。

**原文：** Encoded but Not in Control: Revealing the Grounding Gap in Vision-Language Robot Policies；arXiv 2610.06235，v1 2026-10-05。[版本](https://arxiv.org/abs/2610.06235) · [§2–6](https://arxiv.org/html/2610.06235v1)

保持场景与其他任务条件不变，把指令目标改成另一个可见可达对象；作者在所测 VLA/WAM 中观察到目标仍可解码却常不改变正确对象选择。它明确承接 LangGap 等同场景语义评测。attention 贡献分析是诊断，不是因果证明。

**对项目的意义。** target grounding query 若能重建目标、线性 probe 准确，却不影响控制，仍没有完成项目要解决的问题。模型“受扰动影响”也可能只表现为动作更差，不能算正确使用 grounding。

**建议测法。** 每个场景配多个合法目标，保持 atomic skill、初始状态与目的地一致，统计选中当前指令对象、选中原对象、接近正确但控制失败。再做位置交换、同类多实例和接触部位替换。有效替换要与无意义词/随机句分开；后者主要测输入敏感性。

若做表征替换实验，使用相同场景下真实生成的目标表示，和随机置零控制分开，避免把离开训练分布的崩溃当成语义作用。本文不证明所有模型或所有场景都忽略语言。本轮读 §2–6，未复现实验。返回 [机制链](evidence.md#trace)。
