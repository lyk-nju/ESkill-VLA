# Target Grounding：方法来源索引

当前设计：[docs/target_grounding.md](../../docs/target_grounding.md)。整体实现：[design.md](../../docs/design.md)。本方向关注每臂三角色视觉锚点与局部去噪监督，双臂共享预测器与训练期去噪器。

论文描述与项目实现分开维护。以下卡片提供机制依据；只有当前设计文档确定的模块、损失和接口才进入 Stage 1。

## 当前方法参考

| 工作 | 参考价值 |
| --- | --- |
| [ReconVLA：局部视觉 latent 去噪](reconvla.md) | 当前三角色视觉 latent 的主要监督来源：用局部视觉信息训练预测 Token，保留外观与空间关系。ESkill-VLA 将目标扩展为当前执行器、当前对象及事件终点区域，并采用保留原图布局的画布。 |
| [AffordanceVLA：角色 Query 与空间条件](affordancevla.md) | 提供按交互职责组织 queries、让空间表征参与动作条件的参照。当前将三个角色统一为视觉 latent，使用共享预测器和训练期去噪器。 |

## 按需参考

| 工作 | 保留价值 |
| --- | --- |
| [RoboGround：对象与目的地区分](roboground.md) | 保留操作对象与目的地／参照物的角色区别，解释关系目标为何需要包含参照物。当前事件目标画布保留终点对象及参照物的联合区域。 |
| [3D HAMSTER：末端路径与深度尺度](hamster_3d.md) | 保留悬空末端轨迹与可见表面深度的区别。二维路径像素的背景深度不能直接当末端深度；三维标签需要一致参考系和尺度。 |
| [RIGID：关系信息与特征对齐](rigid.md) | 保留几何信息不必依赖教师特征逐维相等这一认识；与当前画布保留原图布局、关系信息的动机相邻。 |
| [SG-VLA：空间监督与梯度路径](sg_vla.md) | 保留前向信息流、辅助梯度和骨干冻结范围的区别，有助于准确阅读当前联合训练接口。 |
