## 原工作做了什么

条件 VAE 联合推断示范中的软边界与子任务 latent；策略根据当前状态和 latent 产生动作。分段数 M 是超参数，边界先验限制退化划分。研究覆盖 grid-world 和连续 reacher，并使用分层 RL 进行新任务组合。作者明确报告：无监督编码可能对应位置而非预期的对象类别，影响组合泛化。

## 对 atomic skill / target grounding / action representation 的意义与边界

CompILE 提供了 Event 与 atomic skill 联合学习的经典参照，也直接挑战“先分好事件，语义就自然出现”的假设。一个分段器可以把时间边界预测得很好，但将重复空间位置而非重复行为作为子任务身份。

本项目需要分别验证两个命题：事件区间是否对应有用操作单位；这些单位的 atomic skill 是否按预期等价类共享。边界准确率、latent 聚类和操作成功率是三个不同证据，不能相互替代。

该论文的任务环境、输入与现代 VLA 有显著差别，其实验不能直接证明当前机器人场景一定存在同样失败；但它已经给出语义可辨识性不足的实际反例。后续训练元控制器也不同于冻结模型后的示范驱动 in-context 组合。

## 可以区分机制的实验

以相同技能字典和策略骨架比较：仅脚本边界、脚本边界加语义标签、学习边界加语义标签。测试交叉包含“同技能不同位置”和“同位置不同技能”，另将事件顺序变化单独列出。

如果完美边界仍无法改善 atomic skill 的跨对象复用，而少量语义标签有效，首版就应优先改进监督定义，而非投入更复杂的无监督分段。反过来，如果粗标签受限而学习式分段获得更佳闭环组合，也应允许重新定义手工技能粒度。

## 下一步精读

核对分段数和边界先验的敏感性、重建与在线执行之间的误差，以及怎样以较少监督消除位置绑定。不要预设增添一个对比损失就足以解决语义不可辨识性。
