CoT-VLA 将未来图像放进推理过程，适合检验视觉辅助目标与部署时显式中间表示的区别。它为比较 target grounding / action representation 提供替代方案，而不是当前区域接地的同义实现。

## 原工作的接口与证据

| 项目 | 原文方法 |
| --- | --- |
| 骨干 | 支持视觉 token 生成的 VILA-U |
| 图像学习 | 当前图像与语言预测未来图像；机器人数据和无动作语言视频共同训练 |
| 动作学习 | 机器人数据监督；以当前图像、语言和未来图像为条件预测 action chunk |
| 注意力 | 图像生成用 causal attention，动作生成用 full attention |
| 部署 | 生成 subgoal，生成并执行动作段，读取新观测后重复 |

未来帧从数据集指定时间范围采样；训练动作样本含真实未来帧，部署使用预测子目标。方法章节没有将这些采样帧定义为语义事件末帧。[§3 与 Algorithm 1](https://arxiv.org/html/2503.22020v1)

## 对本项目的推论

CoT-VLA 的未来图像提供比当前 target grounding 更多的信息，同时需要推理时生成。与训练期 ReconVLA 式 ROI 重建相比，二者的信息内容、运行成本和出错路径都不同；不能仅以“都做重建”归为同一种方法。

显式视觉中间态可以展示模型想达到什么，但生成图像合理本身不能证明动作对它存在有效依赖。需要在保持当前观察不变时替换未来对象关系，检查动作能否按预期变化，也要看错误目标是否会导致可预测的失败。

## 可区分机制的实验

固定骨干和机器人数据，比较仅动作学习、当前 ROI 辅助监督、未来图像辅助监督、部署期生成未来图像、压缩未来 latent。报告端到端延迟、动作成功和生成错误传播，而不只比较图像质量。

设置真实未来目标与预测未来目标两条评估，量化中间预测误差。事件研究可进一步比较时间采样和事件末状态采样，但需匹配未来距离分布，避免更近目标天然容易带来的混淆。

后续需核验混合预训练数据比例、视觉生成与动作联合训练的独立贡献，以及是否有专门缓解训练真实目标与部署生成目标差异的机制。
