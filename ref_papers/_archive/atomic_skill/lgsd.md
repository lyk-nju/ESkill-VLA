## 原工作做了什么

以连续 Gaussian latent 指定技能，使用语言描述的语义距离约束状态表示，并由内在奖励训练策略。论文通过规则把模拟器状态向量转换为文本，再结合 LLM 与句子表示；不是直接从原始视频无监督获得语言。学习依赖在线 RL，reward-free 指不提供任务奖励，并不意味着没有优化奖励信号。

## 对 atomic skill / target grounding / action representation 的意义与边界

LGSD 将问题从“学习更多样的轨迹”推进到“按什么度量定义有意义的多样性”。一组运动在关节空间差异很大，未必在对象状态或交互结果上有更多变化；反之，细小接触变化可能对应重要的行为类别区别。

这对 atomic skill 的语义字典同样成立：我们选择动词、工具作用或对象效果作为标签，已经注入了何种变化值得区分的假设。语言监督不是中立的语义真值，其粒度和模板会影响所谓原子技能。

当前不建议直接把 LGSD 的在线 LLM/RL 管线加进 Phase 1。更可行的是借鉴它对语义距离和行为多样性的区分，用仿真器可用信息审查 atomic skill 的定义。

## 可以区分机制的实验

在动作能量、时长和基本任务成功率相近的条件下，分别统计轨迹覆盖、对象效果覆盖以及技能标签覆盖。针对同一数据使用不同但合理的行为描述模板，检查技能划分是否稳定。

若技能簇主要随措辞变化而非交互结构变化，应先修订监督来源；若仅使用对象效果会合并控制规律不同的工具或接触模式，则应允许 atomic skill 的粒度包含这些区别。不能把所有运动细节一概视为应消除的噪声。
