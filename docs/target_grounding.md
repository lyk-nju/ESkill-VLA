# Target Grounding：三锚点视觉表征

本页维护空间接地的设计、理由与方法来源，服务于 [idea.md](idea.md)。整体架构与数据接口见 [design.md](design.md)。当前主方案是 **三个带空间信息的视觉 latent + 训练期局部去噪监督**。

## 1. 学习什么，为什么是三个锚点？

操作需要知道执行器当前在哪里、针对哪个对象，以及该对象在本事件结束时应形成什么视觉空间状态。只表示对象类别不够；只回归框又难以保留形状、接触部位和相似对象之间的细节。因此将三个角色都表示为视觉 latent，而非将主输出限定为边界框。

| 锚点 | 表达内容 | 监督来源 |
| --- | --- | --- |
| 当前执行器 \(g_t^{ee}\) | 手／夹爪的位置、形态与局部交互状态 | 当前执行器区域 |
| 当前对象 \(g_t^{obj}\) | 当前被操作对象的位置、外观与局部几何 | 当前对象区域 |
| 事件目标 \(g_t^{goal}\) | 同一对象在 Event 终点的状态及必要空间关系 | 终点对象及放置／接触参照区域 |

这将早期“仅描述当前对象”的 Grounding 扩展为当前状态与事件目标。物体身份可在事件内稳定，视觉状态仍随观测更新。事件目标不等于完整未来视频，也不唯一决定执行器终点或接触姿态。

## 2. 为什么采用局部去噪监督？

借鉴 ReconVLA，用局部重建目标推动模型保留交互所需的细粒度视觉信息。三个预测 latent 条件化训练期去噪器；推理时去掉去噪器，只保留锚点预测与下游条件接口，因此无需在线采样重建图像。预测分支本身仍有计算开销。

局部监督必须保留原图位置及必要参照物。杯子放到盘子上后，单独裁剪杯子的图像可能几乎不变，仅重建紧致裁剪无法表达放置位置。当前位置与终点目标需要共同的空间参照；相机运动时需要对齐。

## 3. 当前网络与监督

在线分支采用三组角色 Query 和共享轻量 Query Decoder。每角色 4 个 Query、两层 Decoder 作为 Stage 1 初始配置；每层包含查询自注意力、对上下文的交叉注意力及 FFN。参数共享，角色 Query 分开学习。

令 \(C_t\) 为当前／历史视觉语言特征，保留图像位置；每组锚点是 \(R\times d\) 个特征，初始 \(R=4\)。沿用 \(g_t^a\) 记号，但它表示一组 Token，不限定为一个向量：

\[
g_t^{ee}=P_\theta(Q^{ee},C_t),\qquad
g_t^{obj}=P_\theta(Q^{obj},C_t),
\]

\[
g_t^{goal}=P_\theta(Q^{goal},[C_t,g_t^{ee},g_t^{obj},u_t]).
\]

当前两锚点与技巧选择并行预测，事件目标随后读取所选可训练技能向量 \(u_t\) 与当前锚点。三组预测 Token 共同输入运动网络和 Action Expert，每次重新观察时更新。Token 不要求与 VAE 目标 latent 具有相同形状。

**SpatialEnc 仅属于训练目标分支。** 三个角色共用冻结 VAE 编码器，采用保留原图布局的局部 RGB 目标画布：

- 当前执行器：保留夹爪及必要邻域。
- 当前对象：保留操作对象及必要邻域。
- 事件目标：保留终点对象与必要参照物的并集外接区域，适当留边。

区域外填固定背景，整幅画布统一缩放；不将局部区域单独放大或居中。相机变化时需建立当前与目标的空间对应。这样保留局部外观及原图位置，避免紧裁剪丢失杯子与盘子的关系。具体画布分辨率和留边写入配置。

\[
y_t^{a*}=E_{VAE}(\operatorname{Canvas}(I_{t_a},R_{t_a}^{a*})),
\quad t_{ee}=t_{obj}=t,\quad t_{goal}=t_e,
\]

\[
y_{t,n}^{a}=\sqrt{\bar\alpha_n}y_t^{a*}+\sqrt{1-\bar\alpha_n}\epsilon,
\qquad \epsilon\sim\mathcal N(0,I).
\]

三个角色共用轻量去噪器，通过角色嵌入 \(e_a\) 区分任务；去噪器接收噪声步、带二维位置编码的加噪视觉网格，并交叉关注对应预测锚点：

固定背景可能占据大部分网格，因此按目标区域及留边加权去噪。将画布区域 mask 按相同空间变换、覆盖率下采样到 VAE 网格，得到 \(m_{b,a,r}\in[0,1]\)，\(r\) 为网格位置：

\[
W_{b,a,r}=w_{bg}+(w_{fg}-w_{bg})m_{b,a,r},\qquad w_{fg}>w_{bg}>0,
\]

\[
\ell_{b,a}=\mathbb E_{n,\epsilon}
\frac{\sum_r W_{b,a,r}\,\operatorname{Mean}_{c}
[(\epsilon_{r,c}-\hat\epsilon_{r,c})^2]}
{\sum_r W_{b,a,r}+\varepsilon},\qquad
\hat\epsilon=D_\psi(y_{t,n}^{a},n\mid g_t^a,e_a),
\]

\[
\mathcal L_{ground}=\sum_{a\in\{ee,obj,goal\}}w_a
\frac{\sum_b v_{b,a}\ell_{b,a}}{\max(1,\sum_b v_{b,a})}.
\]

\(c\) 为 latent 通道，\(v_{b,a}\) 为角色标签有效标记。先按每个样本的空间权重总和归一化，再按角色平均有效样本，避免网格数量或区域面积直接放大损失尺度。区域范围包含必要邻域；VAE 感受野跨越像素边界，网格 mask 是监督权重而非精确语义分割。背景保留非零权重，前景／背景误差用于训练诊断。权重调整监督重点，不保证锚点一定被使用。

区域 mask 仅用于构造监督画布和损失权重，真实 ROI、未来图像和终点位置不进入在线预测分支。冻结 VAE 仍接收 RGB，不直接增加 mask 输入通道。去噪、下游轨迹和动作损失共同训练锚点预测器；推理关闭 VAE 目标分支和去噪器，不在线生成图像。

Stage 1 就采用上述三锚点网络，不添加 OBB 多候选头或接触方向分类头。固定背景画布、共享角色 Decoder 和三锚点监督属于本项目实现选择，尚待训练验证。

## 4. 参考来源与验证重点

| 来源 | 借鉴的机制 | 本项目的扩展 |

| [ReconVLA](../ref_papers/target_grounding/reconvla.md) | 以预测特征条件化局部 VAE latent 去噪，辅助动作学习 | 从局部对象监督扩展为当前执行器、当前对象与事件目标三个视觉锚点 |

更多机制保留在 [空间接地论文库](../ref_papers/target_grounding/README.md)。三锚点与未来局部目标的组合是本项目设计，不应写成原论文已有结论。

Stage 1 先落实三锚点标签、原图位置、参照物和训练／推理条件的一致性，跑通去噪监督及动作接入。重建指标和 attention 图用于定位问题，主要评价完整模型的平均任务成功率，不把三锚点和各监督形式的逐项消融列为前置要求。示范终点只提供一个已实现结果，当前确定性目标预测不保证覆盖所有合法目标状态。
