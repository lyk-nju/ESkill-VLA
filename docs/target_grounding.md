# Target Grounding：每臂三锚点视觉表征

本页维护空间接地的设计、理由与方法来源，服务于 [idea.md](idea.md)。整体架构与数据接口见 [design.md](design.md)。当前主方案是 **每臂三个带空间信息的视觉 latent + 共享训练期局部去噪监督**。双臂可以具有不同对象和事件终点，仍共用同一网络。

## 1. 学习什么，为什么是三个锚点？

操作需要知道执行器当前在哪里、针对哪个对象，以及该对象在本事件结束时应形成什么视觉空间状态。只表示对象类别不够；只回归框又难以保留形状、接触部位和相似对象之间的细节。因此将三个角色都表示为视觉 latent，而非将主输出限定为边界框。

| 锚点 | 表达内容 | 监督来源 |
| --- | --- | --- |
| 当前执行器 \(g_t^{r,ee}\) | 本臂手／夹爪的位置、形态与局部交互状态 | 当前执行器区域 |
| 当前对象 \(g_t^{r,obj}\) | 本臂当前被操作对象的位置、外观与局部几何 | 当前对象区域 |
| 事件目标 \(g_t^{r,goal}\) | 同一对象在本臂 Event 终点的状态及必要空间关系 | 终点对象及放置／接触参照区域 |

这将早期“仅描述当前对象”的 Grounding 扩展为当前状态与事件目标。物体身份可在事件内稳定，视觉状态仍随观测更新。事件目标不等于完整未来视频，也不唯一决定执行器终点或接触姿态。

## 2. 为什么采用局部去噪监督？

借鉴 ReconVLA，用局部重建目标推动模型保留交互所需的细粒度视觉信息。三个预测 latent 条件化训练期去噪器；推理时去掉去噪器，只保留锚点预测与下游条件接口，因此无需在线采样重建图像。预测分支本身仍有计算开销。

局部监督必须保留原图位置及必要参照物。杯子放到盘子上后，单独裁剪杯子的图像可能几乎不变，仅重建紧致裁剪无法表达放置位置。当前位置与终点目标需要共同的空间参照；相机运动时需要对齐。

## 3. 当前网络与监督

在线分支采用三组基础角色 Query，加左右臂嵌入，通过同一轻量 Query Decoder 预测。每臂每角色 4 个 Query，共 24 个 Token；两层 Decoder 作为 Stage 1 初始配置，每层包含组内查询自注意力、对上下文的交叉注意力及 FFN。角色 Query 分开学习、跨臂共享，不复制两套预测器。

令 \(C_t\) 为保留图像位置的当前／历史视觉语言特征，\(r\in\{L,R\}\) 为臂，\(a\in\{ee,obj,goal\}\) 为角色。每组 \(g_t^{r,a}\) 是 \(R_g\times d\) 个特征，初始 \(R_g=4\)，不限定为一个向量：

\[
g_t^{r,ee}=P_\theta(Q^{ee}+e_r^{arm},C_t),\qquad
g_t^{r,obj}=P_\theta(Q^{obj}+e_r^{arm},C_t),
\]

\[
g_t^{r,goal}=P_\theta(Q^{goal}+e_r^{arm},[C_t,g_t^{r,ee},g_t^{r,obj},u_t^r]).
\]

每臂当前两锚点与技巧选择并行预测，事件目标随后读取本臂所选技能向量 \(u_t^r\)、当前锚点与全局上下文。双臂锚点共同输入运动网络和 Action Expert，每次重新观察时更新。Token 不要求与 VAE 目标 latent 具有相同形状。

**SpatialEnc 仅属于训练目标分支。** 所有臂／角色共用冻结 VAE 编码器，采用保留原图布局的局部 RGB 目标画布：

- 当前执行器：保留夹爪及必要邻域。
- 当前对象：保留操作对象及必要邻域。
- 事件目标：保留终点对象与必要参照物的并集外接区域，适当留边。

区域外填固定背景，整幅画布统一缩放；不将局部区域单独放大或居中。相机变化时需建立当前与目标的空间对应。这样保留局部外观及原图位置，避免紧裁剪丢失杯子与盘子的关系。具体画布分辨率和留边写入配置。

\[
y_t^{r,a*}=E_{VAE}(\operatorname{Canvas}(I_{t_{r,a}},R_{t_{r,a}}^{r,a*})),
\quad t_{r,ee}=t_{r,obj}=t,\quad t_{r,goal}=t_e^r,
\]

\[
y_{t,n}^{r,a}=\sqrt{\bar\alpha_n}y_t^{r,a*}+\sqrt{1-\bar\alpha_n}\epsilon,
\qquad \epsilon\sim\mathcal N(0,I).
\]

所有臂／角色共用轻量去噪器，通过角色和臂嵌入区分监督对象；去噪器接收噪声步、带二维位置编码的加噪视觉网格，并交叉关注对应预测锚点。

固定背景可能占据大部分网格，因此按目标区域及留边加权去噪。将画布区域 mask 按相同空间变换、覆盖率下采样到 VAE 网格，得到 \(m_{b,r,a,x}\in[0,1]\)，\(x\) 为网格位置：

\[
W_{b,r,a,x}=w_{bg}+(w_{fg}-w_{bg})m_{b,r,a,x},\qquad w_{fg}>w_{bg}>0,
\]

\[
\ell_{b,r,a}=\mathbb E_{n,\epsilon}
\frac{\sum_x W_{b,r,a,x}\,\operatorname{Mean}_{c}
[(\epsilon_{x,c}-\hat\epsilon_{x,c})^2]}
{\sum_x W_{b,r,a,x}+\varepsilon},\qquad
\hat\epsilon=D_\psi(y_{t,n}^{r,a},n\mid g_t^{r,a},e_a,e_r^{arm}),
\]

\[
\mathcal L_{ground}=\sum_{a\in\{ee,obj,goal\}}w_a
\frac{\sum_{b,r}v_{b,r,a}\ell_{b,r,a}}{\max(1,\sum_{b,r}v_{b,r,a})}.
\]

\(c\) 为 latent 通道，\(v_{b,r,a}\) 为逐臂、逐角色标签有效标记，并排除实际不存在的臂。先按每个目标的空间权重总和归一化，再按角色平均有效批次／臂样本，避免网格数量、区域面积或臂数直接放大损失尺度。区域范围包含必要邻域；VAE 感受野跨越像素边界，网格 mask 是监督权重而非精确语义分割。背景保留非零权重，前景／背景误差用于训练诊断。权重调整监督重点，不保证锚点一定被使用。

idle 或无对象 return 的当前 ee 仍可监督，obj／对象 goal 无定义时仅屏蔽对应损失；hold 保留对象及有效终态。两臂共同追求同一对象终态时，按 Event 标注约定对齐语义终点、目标时间与参照区域；独立操作或不同效果的交接保留各自终点。共享 actor ID 本身不意味着 goal 标签应完全相同。

区域 mask 与角色有效性仅用于监督，真实 ROI、对象 ID、未来图像和终点位置不进入在线预测分支。不根据真值有效性删除在线 Token；实际存在的 idle 臂也保留预测槽位。冻结 VAE 仍接收 RGB，不直接增加 mask 输入通道。去噪、下游轨迹和动作损失共同训练锚点预测器；推理关闭 VAE 目标分支和去噪器，不在线生成图像。

Stage 1 就采用上述每臂三锚点共享网络，不添加 OBB 多候选头、接触方向分类头或协作头。固定背景画布、共享角色 Decoder 和三锚点监督属于本项目实现选择，尚待训练验证。

更多机制保留在 [空间接地论文库](../ref_papers/target_grounding/README.md)。三锚点与未来局部目标的组合是本项目设计，不应写成原论文已有结论。

Stage 1 先落实三锚点标签、原图位置、参照物和训练／推理条件的一致性，跑通去噪监督及动作接入。重建指标和 attention 图用于定位问题，主要评价完整模型的平均任务成功率，不把三锚点和各监督形式的逐项消融列为前置要求。示范终点只提供一个已实现结果，当前确定性目标预测不保证覆盖所有合法目标状态。
