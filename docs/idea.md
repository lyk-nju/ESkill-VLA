# ESkill-VLA：研究目标

**E 代表 Event。** 我们希望从有限机器人示范中学习可复用的视觉运动知识，并在对象、位置或任务组合改变时使用这些知识。模型输入只来自当前图像与任务指令，几何状态与实例关系用于离线监督。

当前先验证视觉 Grounding：冻结预训练 π0.5 VLM，通过两个小型读取分支学习任务目标和夹爪局部表征。Current 根据完整任务与观察确定下一步交互目标；Subject 表征真实夹爪所在区域。任务改变时 Current 可以切换，Subject 的前向保持不受任务文本影响。

我们关注三个问题：

1. Current 能否随任务和交互状态正确选目标，而不是记住固定场景位置？
2. 移动物体、改变背景或替换任务后，模型能否保持定位能力？
3. 得到的表征后续能否帮助 Motion／Action，而不只是降低视觉重建损失？

前两项通过独立验证轨迹、目标替换、位置扰动和读出检查评估。第三项尚需接回动作系统后的干预与闭环实验，当前视觉专项不直接证明控制收益。

Event 为离线监督提供阶段与实体对应，同一完整任务在 Pick 和 Place 阶段可以定位不同实例。反事实任务先限定为语义明确的组合；没有恢复动作标签时，不声称已经学会“抓错物体后纠错”。

架构见 [Design](design.md)，标签见 [Grounding](target_grounding.md)，增强见 [Augmentation](augmentation.md)。历史 Skill→Motion→Action 研究与实验保留在 [history/](history/README.md)，不作为当前视觉专项的训练要求。
