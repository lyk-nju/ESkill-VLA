# ESkill-VLA 的研究问题

本分支研究从 Current 到事件级二维运动计划的映射。输入是当前 RGB 和完整任务，可加入同帧腕图。 [模型设计](design.md)

## 同一条指令在不同阶段应关注谁

以 `Put the milk in the basket` 为例。示范中的 Pick 阶段以 milk 为 Current，Place 阶段以 basket 为 Current。整条指令保持相同，模型需要从当前图像判断阶段。换成另一条任务指令时，同一张图像也可能有不同的 Current。Event 标签提供训练与离线评估依据，推理时每次收到新图像就重新预测。

## 怎样检验定位能否帮助规划

| 研究问题 | 可观察的证据 |
| --- | --- |
| Current 能否随任务和阶段切换？ | 在固定的 A–E 定位清单上比较同帧不同指令，再沿完整示范查看 Pick／Place 概率和接收物区域的注意力。若有回放抓持记录，可把双侧指垫接触与标注边界分别对齐。 |
| 同一技能能否把计划转向新目标？ | 固定同一帧、技能路由、视觉特征和 Motion Query，只替换 Current 先验，测量预测轨迹沿 A→B 方向的位移。与同条件训练的零先验配方及自然更换指令的结果对照。 |
| 技能专家对轨迹有什么贡献？ | 固定场景与目标，比较使用预测专家、指定其他专家以及移除专家后的轨迹。结合真实示范上的轨迹误差判断变化是否符合操作语义。 |

Current 的目标分布可以从反事实指令或物体移位图像取得。Skill 和 Trace 的监督则保留给仍与原始示范一致的样本。研究假设是，更丰富的目标定位监督有助于把有限的运动示范复用到新的对象与位置组合。实际训练数据与评测组合的重合情况须单独核对。[数据协议](data.md)

当前输出是二维计划。已完成的小模型短测验证了先验替换和专家干预可以执行；KLAL 20k 的定位保留程度、跨组合的轨迹质量仍待实测。[实验配方与诊断](../experiments/motion_planner/README.md)
