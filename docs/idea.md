# ESkill-VLA：From Trajectory Imitation to Event-Centric Learning

**面向可泛化机器人操作的事件中心任务知识学习**

本页维护稳定的研究问题、归纳偏好与验证目标。它不随每篇新论文或实现参数变化而扩写。当前方案均为研究假设与待验证设计，尚无本项目实验结论。

## 1. 根本问题：机器人应该从示范中学习什么？

> 什么样的数据组织方式、学习目标与训练方法，能够让机器人从有限示范中学习可复用、可泛化的任务知识，并在实际交互中持续理解当前情境、选择合适行为，推进任务完成？

我们关心的能力包括：理解当前应执行什么技巧、针对什么对象及目标状态，在不同条件下调整运动，以及根据实际效果继续执行后续行为。成功率、动作误差与表征可视化分别提供部分证据，不能独自代表这些能力。

核心研究对象是示范背后的行为语义、交互目标与实现规律。Atomic Skill、视觉 latent 和运动 Token 都是组织这些知识的候选手段，而不是研究的最终目的。

## 2. 为什么反思轨迹中心监督？

典型 VLA 根据观察、语言与机器人状态学习动作片段：

\[
A_{t:t+H}\sim\pi_\theta(A\mid O_{\le t},L,S_t).
\]

动作监督不可替代，但一条示范轨迹是在特定环境、初态与本体下完成任务的一种实现。它将行为语义、目标对象、空间条件和运动细节混合在同一监督对象中，而这些信息具有不同的稳定性与复用范围。

例如拿起杯子可以从左侧、右侧或绕障接近。这里既有环境变化引起的运动适配，也有相同条件下多条合法轨迹共存的多模态性。示范中的某条路径不是唯一正确答案。

我们并不预先断言行为克隆学不到目标，生成式动作模型也能够表达多模态。研究假设是：**在数据有限和测试分布变化时，显式组织行为语义、目标条件与执行过程，可能比仅靠动作拟合更高效地提取可复用知识。**

## 3. 用 Event 组织目的、过程与效果

一个复杂任务可以由多个持续时间可变、具有相对一致操作意图的 Event 组织。RoboTwin 的程序化任务生成提供了直观启发：操作原语与目标先被定义，再由运动控制产生具体轨迹；训练数据可以保留并利用其中可核验的结构。

\[
\tau=\{(O_t,S_t,A_t)\}_{t=1}^{T},\qquad
\tau\longrightarrow\left\{\{\mathcal E_i^r\}_{i=1}^{N_r}\right\}_{r\in\{L,R\}}.
\]

**一个 Event 对应一次 Skill 执行**：Event 是具体示范中的操作区间，Skill 是可跨不同 Event 复用的操作类型。同一 Skill 可以在不同对象或情境下对应多个 Event。双臂场景按臂组织事件流：同臂有序、跨臂可并发，并保留共同目标与任务依赖，不强行将全部操作串成一条全局事件序列。

Event 是数据与监督的组织单位，保留内部完整观测、状态和动作，并关联技巧语义、对象角色、目标状态及可获得的实际结果。它不要求固定帧数、单一 Token 或一次执行完整事件。

语义事件、接触关键状态、运动预测时域与动作执行窗口分别设计。技巧粒度须与边界一致；夹爪闭合不是成功抓持的充分条件。具体方法依据见 [event_organization.md](event_organization.md)。

## 4. 三类互补知识与归纳偏好

四个 Insight 来自我们对操作知识的归纳偏好：Event 组织数据，另外三个方向定义事件内部值得学习的信息。它们可以共享网络特征，不要求统计独立。

| 方向 | 希望学习的知识 | 当前实现方向；细节以对应文档为准 |
| --- | --- | --- |
| [Atomic Skill](atomic_skill.md) | 当前执行什么技巧，以及动作窗口内接下来如何安排操作 | 当前技能用冻结文本原型分类，未来技能读取事件表征预测；共享技能表逐步条件化动作 |
| [Target Grounding](target_grounding.md) | 当前执行器、当前对象，以及对象在事件终点的视觉空间状态 | 三锚点视觉 latent，训练期局部去噪监督 |
| [Action Representation](action_representation.md) | 当前条件下直到事件终点的有序粗空间运动 | 固定 Motion Queries，归一化弧长采样的三维路径监督 |

当前双臂设计为每臂预测当前技巧、锚点和运动表示，再预测固定动作窗口内的未来技能序列，以逐步技能条件驱动同一个联合动作专家。语义词表、技能表和网络参数跨臂共享，两臂可以有不同的技能安排与切换位置。

技巧提供相对稳定的操作语义，并与共享解码网络共同学习操作先验；对象身份可以稳定，而视觉位置和交互状态需要随观测更新；运动描述具体实现，允许同一技巧与对象对应不同路径。当前锚点与技巧可以并行预测，事件目标与运动再综合相关条件。

事件目标采用 **Event-boundary Object State Grounding**：使用同一被操作对象在当前 Event 结束时的视觉区域，监督模型学习该对象应达到的目标状态。对象的终点视觉状态只是目标的一个操作化代理，不必然表达稳定抓持、接触力等全部期望关系。未来物体状态也不能唯一确定末端接触位姿。因此任务上下文、机器人状态与真实动作监督仍保留。

同一意图的多模态运动是研究对象的性质，不是对当前模型能力的承诺。首轮确定性粗轨迹监督提供轻量起点，尚不显式学习可采样的多模态运动分布；其局限需与控制表现一起检验。

## 5. 从知识表示到持续任务执行

整体路径是：**事件组织监督 → 预测当前技能、对象目标与剩余运动 → 预测每臂未来技能安排 → 逐动作步条件化 Action Expert → 新观察更新决策。**

固定动作块可能跨 Event，当前事件表征因此参与对后续操作与切换位置的预测。研究重点是这些事件知识能否改善技能安排与实际执行。粗路径按弧长组织，未来技能按动作步组织，两者通过注意力联系；这种接口提供计算通路，收益仍需训练与闭环结果验证。

动作执行始终受真实机器人动作监督约束。中间表征需要能被控制器实际利用；仅重建得好、类别分得开或 attention 看起来合理，都不足以证明行为能力改善。

训练可使用完整事件构造监督，推理只能使用当前及历史可得信息。模型预测的目标、粗路径和技能安排都是估计，训练与推理均使用预测技能作为动作条件。Goal／Motion 只覆盖当前 Event，未来技能不等于未来对象或完整世界状态；同技能的连续事件也可能操作不同对象。

**Action Completion 不等于 Goal Achievement。** 抓取失败后，合理行为可能是保持操作目的并调整运动，而不是因为夹爪已闭合就推进任务。事件结构为这种学习提供基础；真正验证恢复能力仍需要失败状态、恢复行为与反馈数据。本阶段持续执行指根据新观察调整决策，不要求部署时在线更新模型参数。

## 6. 跨本体目标与阶段一范围

跨本体共享从接口设计时考虑：技巧使用可对应的操作语义，Grounding 描述视觉交互角色，运动接口使用末端空间变化，机器人控制格式由状态适配与 Action Expert 处理。

[LAPA](../ref_papers/action_representation/lapa.md) 与 [ConLA](../ref_papers/action_representation/conla.md) 启发我们利用无机器人动作标签的视频，并区分运动与无关外观。当前简化方案未直接采用其视频量化教师或对比目标，不能将这些已有结果当作本方案的迁移证明。

当前 Stage 1 使用机器人示范及可获得的三维运动监督。后续若加入人类视频，需要建立手部运动、相机位姿、尺度与执行器参考点的对应；不同身体的接触机制、可达性与控制精度仍需适配。统一接口只是必要设计条件，单一本体上的泛化不等于跨本体迁移。

## 7. 当前验证与长期研究方向

**Stage 1 采用上述新设计，优先跑通完整方法的训练、推理与闭环评测。** 不要求先复现旧方案、完成大批消融或新的泛化评测。平均任务成功率评价整体表现，常规模块指标用于定位问题；出现具体问题再做针对性分析，具体完成标准见 [design.md](design.md)。

后续可逐步研究未见技巧—对象组合和事件序列、人类—机器人运动迁移，以及固定模型参数下的示范 Context 重组。这些能力目标不作为当前训练启动或 Stage 1 完成的门槛。

| 长期假设 | 待检验主张 |
| --- | --- |
| H1：Event-Centric Organization | 语义事件组织可能改善任务知识复用 |
| H2：Semantic–Target Factorization | 技巧与细粒度空间条件的分工可能改善未见组合 |
| H3：Interaction-Centric Motion Learning | 技巧／目标条件下的空间运动监督可能改善控制与后续迁移 |
| H4：Event-Based Knowledge Composition | 事件知识可能支持新序列、新对象绑定与示范 Context 重组 |

这些假设保留研究方向，不转化为本阶段逐项证明的实验清单。Stage 1 的平均成功率提升首先说明整体方案在所评测任务上有用，不自动证明全部长期能力或各模块的独立贡献。

我们最终要验证的是：**以 Event 组织示范，并明确监督可复用技巧、交互目标与运动过程，是否能让机器人从有限数据中学到更可组合、更可迁移、能支持持续任务推进的操作知识。**
