# DeCo：完整交互与事件衔接

**用途：当前方法参考。** 本卡解释来源，不增加实施要求；当前方法见 [方向文档](../../event_organization.md)，实现以 [design.md](../../design.md) 为准。

## 原工作机制

以完整夹爪交互组织 atomic tasks，用关键帧／目标位姿训练低层策略，结合 VLM 调度和空间衔接。关键帧与完整交互处于不同层级。

## 对本项目的参考价值

说明 Event 的粒度与进入状态、结束效果相关，而非按固定帧数或每次夹爪跳变机械切割。AtomSkill §III-A 明确引用其分段方法。

## 采用边界

原方法的在线调度、位姿判断和规划不是当前实现组件。空夹、推物、持续抓持等操作不能只依靠夹爪开放度定义事件。
