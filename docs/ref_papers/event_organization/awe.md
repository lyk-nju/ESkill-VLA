# AWE：路径几何与事件粒度

**用途：补充机制，按需阅读。** 本卡解释来源，不增加实施要求；当前方法见 [方向文档](../../event_organization.md)，实现以 [design.md](../../design.md) 为准。

## 原工作机制

给定最大轨迹重构误差，使用动态规划选择最少 waypoint，并以相邻点插值表示路径。选择依据来自几何轨迹。

## 对本项目的参考价值

帮助区分 Event 语义粒度与粗路径几何精度：一个语义事件可以包含多个必要转弯，几何静止也可能伴随抓放语义变化。

## 采用边界

当前仍按 design.md 的归一化弧长采样构造固定数量 XYZ 标签；此卡不引入 AWE 优化器。几何重构误差小也不保证接触成功。
