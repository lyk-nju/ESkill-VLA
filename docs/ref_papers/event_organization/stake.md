# StaKe：辅助监督与部署 Token

**用途：研究依据，按需阅读。** 本卡解释来源，不增加实施要求；当前方法见 [方向文档](../../event_organization.md)，实现以 [design.md](../../design.md) 为准。

## 原工作机制

在 π0.5 增加阶段与关键帧 query，分别分类 motion/skill 二元阶段、回归下一夹爪变化处或终态的关节关键帧；与动作 Flow Matching 联合训练，推理保留 query 而移除辅助头。

## 对本项目的参考价值

直接说明“训练期辅助头监督、部署保留中间 token”的接口如何成立，关联当前／终点对象和 Motion tokens 的训练／推理分工。

## 采用边界

二元阶段不是本项目的语义 Skill，关节关键帧也不是跨本体运动表示。它作为结构监督参照，不形成额外基线复现或训练阶段要求。
