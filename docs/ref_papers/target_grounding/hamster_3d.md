# 3D HAMSTER：末端路径与深度尺度

**用途：补充机制，按需阅读。** 本卡解释来源，不增加实施要求；当前方法见 [方向文档](../../target_grounding.md)，实现以 [design.md](../../design.md) 为准。

## 原工作机制

高层从标定 RGB-D 和语言预测 (u,v,metric depth) waypoint 与夹爪状态，辅以稠密深度重建；反投影后供点云条件低层策略使用。

## 对本项目的参考价值

保留悬空末端轨迹与可见表面深度的区别。二维路径像素的背景深度不能直接当末端深度；三维标签需要一致参考系和尺度。

## 采用边界

当前由三维 EEF 与标定生成二维轨迹监督，不新增 RGB-D 输入、深度编码器或点云控制器。原文的额外几何输入不能视为本项目 RGB 条件下已有能力。
