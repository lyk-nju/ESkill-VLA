# Target Grounding：背景机制笔记

本页将 12 项较远路线压缩为机制、参考价值与适用边界。这里没有待实施方案、实验清单或排期；当前方法见 [方向文档](../../target_grounding.md)，代码实现以 [design.md](../../design.md) 为准。

来源沿用既有阅读记录，本次没有重新联网核验或复现。原文的模块、训练流程和结果只描述原工作。

<a id="robopoint"></a>

## RoboPoint 空间关系与交互点监督

[论文来源](https://arxiv.org/abs/2406.10721) · [出版／作者入口](https://robo-point.github.io/)

阅读范围：作者方法页 Overview、Dataset。

**原方法：** 用合成空间关系训练指令条件交互点预测，部署结合深度把二维点转为三维目标并规划执行。

**保留价值与边界：** 保留指令到空间位置的监督来源。点预测并不提供完整动作策略，深度与规划器属于原部署依赖。

<a id="rt_affordance"></a>

## RT-Affordance 关键交互姿态作为条件

[论文来源](https://arxiv.org/html/2411.02704v1)

阅读范围：v1 §III。

**原方法：** 关键时刻的末端姿态组成 affordance plan，与语言共同条件化策略；图像投影可包含位置、朝向和时序。

**保留价值与边界：** 保留接触姿态计划和当前对象区域的语义区别。计划可由用户或模型提供，依赖标定；当前／终点对象 tokens不是其姿态计划接口。

<a id="graspvla"></a>

## GraspVLA 的感知与动作监督对齐

[论文来源](https://arxiv.org/html/2505.03233v3) · [出版／作者入口](https://pku-epic.github.io/GraspVLA-web/)

阅读范围：v3 §4、§5.1。

**原方法：** 互联网 grounding 与合成机器人数据联合训练二维对象框、抓取姿态及动作；Flow Matching 专家读取 VLM 的中间 token KV。

**保留价值与边界：** 保留跨监督来源共享感知—动作接口的实例。原数据与抓取专门化设置不同；最多三次尝试成功不能当单次成功，也不证明任意长任务泛化。

<a id="hamster"></a>

## HAMSTER 的二维轨迹引导接口

[论文来源](https://arxiv.org/html/2502.05485v4) · [出版／作者入口](https://hamster-robot.github.io/)

阅读范围：v4 §4.1–4.2。

**原方法：** 高层 VILA 从图像和语言生成二维末端路径与夹爪状态，经 RDP 简化，低层三维视觉控制策略执行。

**保留价值与边界：** 保留粗空间路径连接任务理解和控制的背景。二维归一化路径没有度量深度；一次高层规划不同于当前每步重估 Latent Motion，文中讨论人类跟踪不等于已证明纯人类视频迁移。

<a id="lotus_3d"></a>

## 3D-LOTUS++ 的技能与对象几何接口

[论文来源](https://arxiv.org/html/2410.01345v2) · [出版／作者入口](https://www.di.ens.fr/willow/research/gembench/)

阅读范围：v2 §IV-A–C、§V-A。

**原方法：** LLM 用预定义操作规划，检测／分割和 RGB-D 获得对象点云，以操作对象、目标、机器人、障碍物角色编码供三维策略使用。

**保留价值与边界：** 保留角色几何与技能条件分工的先例。与持续学习 LOTUS 不同；当前不引入外部规划、点云角色编码或停止头。

<a id="mimicplay"></a>

## MimicPlay 的三维手轨迹与潜在计划

[论文来源](https://arxiv.org/html/2302.12422v2) · [出版／作者入口](https://mimic-play.github.io/)

阅读范围：v2 §3.1–3.3、§4；官方仿真使用 robot play。

**原方法：** 同环境人类 play 经标定相机重建三维手轨迹；高层以 GMM 轨迹目标学习 latent plan，冻结后用机器人数据训练低层。

**保留价值与边界：** 保留三维手运动监督与机器人动作适配的实例。依赖相机标定、同环境人类数据及机器人数据，不能推广为任意互联网 RGB 视频零适配执行。

<a id="susie"></a>

## SuSIE 的未来子目标图像与控制

[论文来源](https://arxiv.org/html/2310.10639v1) · [出版／作者入口](https://rail-berkeley.github.io/susie/)

阅读范围：v1 §4.1–4.3 与问题定义。

**原方法：** 图像编辑模型从当前 RGB 和语言生成未来 subgoal，机器人数据训练目标条件 BC，部署执行固定步数再刷新目标。

**保留价值与边界：** 保留未来视觉目标与动作控制的连接方式。未来采样范围和刷新频率不等于语义 Event；当前目标 latent 不要求部署生成完整图像。

<a id="cot_vla"></a>

## CoT-VLA 的未来图像与动作联合预测

[论文来源](https://arxiv.org/html/2503.22020v1) · [出版／作者入口](https://cot-vla.github.io/)

阅读范围：v1 §3.1–3.3、Algorithm 1、§4.1。

**原方法：** VILA-U 先生成未来图像，再以其条件生成 action chunk；训练混合机器人数据和有语言无动作视频。

**保留价值与边界：** 保留训练目标与部署预测目标可能不同的接口背景。原动作训练可读真实未来帧，部署使用生成图像；当前在线前向只用预测条件，不引入未来图像生成链。

<a id="vista_visual_conditioning"></a>

## VISTA 的视觉依赖与轨迹偏好训练

[论文来源](https://arxiv.org/html/2602.05049v1) · [出版／作者入口](https://vista-vla.github.io/)

阅读范围：v1 §3.2–3.3、§4.1–4.3。

**原方法：** 未来点轨迹叠加到图像，构造动作偏好训练，再从带轨迹 teacher 蒸馏到无需轨迹的学生；视觉扰动用于分析依赖。

**保留价值与边界：** 保留训练期特权监督与部署输入的区别。视觉敏感不等于正确选目标；当前不增加 DPO 或轨迹蒸馏。这篇 VISTA 与世界模型同名工作不同。

<a id="mind_vla"></a>

## Mind-VLA：按阶段对象建立空间监督

[论文来源](https://arxiv.org/html/2608.04633v2)

阅读范围：v2 §II、III-B–D、IV-A。

**原方法：** 用指令对象顺序及动作线索分配阶段对象，以 canonical 多视图的 VAE／几何目标训练对象 queries，部署由动作读取。

**保留价值与边界：** 保留事件对象绑定与监督区域选择的关联。canonical 形状去中心和尺度后不代表当前度量位姿；当前画布保留原图布局，不替换为 canonical mesh。

<a id="affordvla"></a>

## AffordVLA：以功能区域教师监督替代 ROI 重建

[论文来源](https://arxiv.org/html/2605.17517v1)

阅读范围：v1 §II-C、III、V。

**原方法：** 任务部件概念与 SAM3 派生教师形成 affordance 特征，训练时对齐学生视觉 tokens，部署去除教师。

**保留价值与边界：** 保留功能区域特征蒸馏这一空间监督路线。与 AffordanceVLA 是不同论文；本项目当前采用冻结 FLUX VAE 目标的潜变量直接 MSE，不增加部件教师或特征蒸馏。

<a id="encoded_not_control"></a>

## Encoded but Not in Control：知道目标与按照目标行动分开测

[论文来源](https://arxiv.org/html/2610.06235v1)

阅读范围：v1 §2–6。

**原方法：** 同场景将指令目标换成另一可达对象，分析目标可解码性与实际对象选择的差距。

**保留价值与边界：** 保留能重建／解码目标与动作真正使用目标的区别，辅助指标不直接等于控制效果。attention 诊断不构成因果证明，也不能概括所有模型忽略语言；当前不增加干预实验清单。
