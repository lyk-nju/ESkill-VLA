# ConLA：动作信息与外观捷径

**用途：研究依据，按需阅读。** 本卡解释来源，不增加实施要求；当前方法见 [方向文档](../../action_representation.md)，实现以 [design.md](../../design.md) 为准。

## 原工作机制

将动作与视觉表示分开，以动作类别对比和帧序反转先验约束运动，再量化预训练，机器人微调替换潜动作头。

## 对本项目的参考价值

保留区分交互运动与静态外观的学习动机；同技能仍可能对应不同几何实现，动作类别一致不要求整个运动表示相同。

## 采用边界

使用动作类别意味着并非完全无监督；当前不增加该对比学习或量化模块。共享接口与三维监督本身不保证跨本体不变性。
