# WALL-WM：事件对齐的数据组织

**用途：当前方法参考。** 本卡解释来源，不增加实施要求；历史动作路线见 [方向文档](../../history/action_representation.md)，历史实现见 [joint_design.md](../../history/joint_design.md)。

## 原工作机制

语义事件对齐视频、文字与动作，使用层次标注和平衡采样；视频塔和动作 DiT 联合学习。Event mode 支持变长执行，Unified mode 可用固定动作块；原文另含时长预测与长度分桶。

## 对本项目的参考价值

当前仅借鉴事件对齐的数据组织，将标签关联到有语义意义的区间。原动作目标包含物理三维末端位姿和夹爪信息。

## 采用边界

ESkill-VLA 使用八个固定未来时刻 Queries，只监督当前 Event 内的路径与夹爪命令；不采用剩余时长头、变长视频／动作塔或长度分桶。原文同时改变数据、模型与执行模式，结果不能单独证明事件边界收益。
