# RoboTracer：有序三维粗路径

**用途：有序空间轨迹的背景参考。** 本卡解释来源，不增加实施要求；当前方法见 [方向文档](../../action_representation.md)，实现以 [design.md](../../design.md) 为准。

## 原工作机制

用有序稀疏 Spatial Trace 描述粗路径，每点为图像坐标与绝对深度 (u,v,d)。原模型包含冻结 MapAnything 空间编码、自回归输出、尺度回归及 GRPO 训练，连接规划执行栈。

## 对本项目的参考价值

保留有序粗路径作为动作条件的背景价值。本项目采用每臂八个固定时间查询，在当前 Event 内监督二维 EEF 路径与夹爪命令，具体以方向文档为准。

## 采用边界

本项目的固定时间 Query 与联合开合监督不属于原文实现。原文不少任务采用对象中心 trace；当前标签明确采用末端轨迹。确定性辅助回归不等于已经学得多峰路径分布。
