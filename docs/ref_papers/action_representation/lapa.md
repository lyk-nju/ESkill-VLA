# LAPA：视频监督与机器人动作适配

**用途：研究依据，按需阅读。** 本卡解释来源，不增加实施要求；历史动作路线见 [方向文档](../../history/action_representation.md)，历史实现见 [joint_design.md](../../history/joint_design.md)。

## 原工作机制

当前／未来帧学习量化潜动作，以伪标签预训练 VLM；机器人微调时以真实动作头替换潜动作头。§3.3 脚注记录保留 latent head 再解码的尝试。

## 对本项目的参考价值

保留未来从无机器人动作标签视频学习动作相关知识的出发点；中间监督目标与最终机器人动作空间可以不同。

## 采用边界

当前不训练 LAPA tokenizer 或视频伪标签教师。下游仍需要动作示范，其接口不证明本项目 Latent Motion 的跨本体迁移能力。
