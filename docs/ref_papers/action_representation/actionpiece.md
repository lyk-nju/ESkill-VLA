# ActionPiece：运动几何差异的保留

**用途：补充机制，按需阅读。** 本卡解释来源，不增加实施要求；当前方法见 [方向文档](../../action_representation.md)，实现以 [design.md](../../design.md) 为准。

## 原工作机制

以平移、旋转、夹爪物理距离监督近远排序，约束编码、量化及码字分配，以 PRC 描述解码后的邻域次序；部署使用动作 decoder。

## 对本项目的参考价值

保留同语义下细粒度运动差异的价值，支持 Atomic Skill 的类别共享与 Latent Motion 的具体几何信息分工。

## 采用边界

本项目不采用其 tokenizer 或排序损失；该文不能证明当前 SmoothL1 一定发生路径平均，也不保证任意多模态被保持。默认 Q=1，不能将收益归于多层 RVQ。
