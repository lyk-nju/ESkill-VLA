# CoMo：连续运动与时序方向

**用途：补充机制，按需阅读。** 本卡解释来源，不增加实施要求；历史动作路线见 [方向文档](../../history/action_representation.md)，历史实现见 [joint_design.md](../../history/joint_design.md)。

## 原工作机制

v3 从当前特征与早期时序特征差编码连续运动，以相邻时间正例、反转负例和重建训练；视频伪标签与真实动作使用不同轻量输出头。

## 对本项目的参考价值

保留有向运动与时序变化的监督价值。当前 Motion Queries 的时间编码表示固定未来偏移；它与视频时序对比属于不同实现。

## 采用边界

当前不增加连续视频教师或时序对比损失。v3 的 S-PCFC 限定背景变化较小的数据，不能证明任意人类视频完全去外观。
