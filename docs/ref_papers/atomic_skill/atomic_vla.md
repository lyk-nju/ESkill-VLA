# AtomicVLA：技能条件与参数路由

**用途：当前方法参考。** 本卡解释来源，不增加实施要求；当前方法见 [方向文档](../../atomic_skill.md)，实现以 [design.md](../../design.md) 为准。

## 原工作机制

think/act 模式生成规划、技能与动作；技能嵌入路由 top-1 技能专家，并与共享专家结合。规则和视频模型校正技能标注，新技能可扩展专家。

## 对本项目的参考价值

提供显式技能语义路由、Shared Expert 与 Top-1 专门化专家的参考。本项目在 VLM 输出端用连续 Query 驱动 6+1 小型专家，输出 Skill Prior 调制 Motion。

## 采用边界

原论文的专家位于动作专家内部 FFN；本项目专家位于 VLM 输出端，且仅通过 Motion 条件化 Action，不照搬 think/act 模式。专家编号、对象无关语义与在线选择准确性不是同一概念；硬路由的下游梯度不穿过 argmax。
