# DASL：训练辅助与部署条件

**用途：补充机制，按需阅读。** 本卡解释来源，不增加实施要求；当前方法见 [方向文档](../../atomic_skill.md)，实现以 [design.md](../../design.md) 为准。

## 原工作机制

低频策略预测 VQ 技能，在预设间隔复用；高频 Decision Transformer 产生动作。latent trajectory diffusion 仅在训练期规整表示，整体联合优化。

## 对本项目的参考价值

保留辅助监督头与部署条件的区别；训练中学习运动结构，并不意味着部署必须运行相同生成过程。

## 采用边界

预设频率不等于语义事件边界。当前不引入 VQ、diffusion 正则或独立高低频控制器。
