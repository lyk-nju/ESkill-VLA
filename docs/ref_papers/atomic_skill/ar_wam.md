# AR-WAM：可学习操作条件

**用途：当前方法参考。** 本卡解释来源，不增加实施要求；当前方法见 [方向文档](../../atomic_skill.md)，实现以 [design.md](../../design.md) 为准。

## 原工作机制

外部 agent 给出操作类别与目标框，可学习操作嵌入和视觉接地条件经调制进入共享策略。

## 对本项目的参考价值

提供离散操作条件与对象空间条件分别参与控制的参照；可学习的操作向量具有执行层面的用途。

## 采用边界

外部操作输入不是自主技能识别。当前由模型预测 Skill ID，三锚点与运动 Token 按 design.md 构建，不增加外部 agent、原世界模型或恢复系统。
