# w²VLA：文本技巧与 FiLM

**用途：当前方法参考。** 本卡解释来源，不增加实施要求；历史动作路线见 [方向文档](../../history/atomic_skill.md)，历史实现见 [joint_design.md](../../history/joint_design.md)。

## 原工作机制

冻结文本特征经 MLP 形成技巧条件，用 FiLM 调制控制特征，空间条件另行注入；原系统还包含视觉路由与训练时视觉遮蔽。

## 对本项目的参考价值

参考条件通过 FiLM 改变运动计算及训练时视觉遮蔽的机制。本项目使用连续 Skill-MoE prior 调制 Motion，视觉遮蔽仅作用于 Action 读取原始视觉 K/V 的可见性。

## 采用边界

原文技巧短语可包含目的地或实体，其视觉遮蔽接口也不同于本项目的 π0.5 原始 K/V mask。连续语义专家、固定时间 Motion 与 Action-side 遮蔽是本项目组合，不能把原论文效果直接外推；实际 Motion 控制作用仍需行为干预验证。
