# Grounding 验收与能力边界

当前先验证任务目标与夹爪区域的视觉读取。Checkpoint 保存、loss 有限和图像标签一致属于技术检查；位置泛化、语义选择及控制收益需要分别验证。

## 数据与增强验收

1. 核对固定父轨迹划分及所有运行时文件，验证不应用训练增强。
2. 从保存结果回读全场景区域：Current 红框、其他物体绿框、夹爪蓝框；检查 Event 首／中／末帧的目标切换。
3. 查看增强前后图像、干净 Current／Subject 画布及真实 VAE 重建，核对 Copy 后标签位置、保护区及几何同步。
4. 按任务统计 `target_swapped`／`copy_applied`／`target_moved`，区分没有候选、原位置受阻及无可行落点。检查原生遮挡、出画和增强后失效分别计数。

当前保存框忽略外部遮挡，而画布保留实际遮挡。不能用部分可见 ROI 推断完整框错误，也不能把完全不可见的外观当成已恢复真值。数据核验记录放 [check/test/](../data/libero/atomic-vla/check/test/README.md)，视频放其 `video/`。

## 模型技术检查

使用明确来源的真实 π0.5／FLUX 权重，检查前向、Current／Subject 有效损失、梯度、BF16、DDP、验证、完整 checkpoint 保存与回读。验证 VLM／VAE 无梯度，两路投影和 Decoder 得到梯度；同图替换任务时 Subject 前向相同。

已有 [真实双卡 8 步记录](../experiments/current_grounding_fused/README.md) 包括一次视觉塔前向、Subject 文本独立性和 checkpoint 回读。这个短测不证明训练收敛；随机小模型也不代替真实权重检查。

## 语义与位置泛化

用固定独立验证轨迹、相同帧和任务比较增强／无增强配方。检查同图不同完整任务、同任务不同抓持状态、目标位置变化、同类干扰物、背景变化及原生遮挡。验证应同时记录正确实体选择、区域空间读出和无效目标数量，不能只看 VAE MSE。

Current／Subject 输出的是 latent，不是直接 bbox 分类器。若使用解码图构造 bbox 或空间指标，必须固定解码／阈值规则并与真实框比较；画布亮度不等于存在置信度。当前 `target_presence_confidence` 未定义，不能据此报告识别置信度。

新构造的反事实／位置扰动检查用于机制诊断，不自动成为独立真实任务集。位置扰动、原始数据和训练组合关系应记录，避免把派生样本当成新增独立示范。

## 后续动作验证

当前专项没有 Motion／Action 前向，不能直接交给 LIBERO／Plus 客户端执行动作。待动作条件接入后再运行闭环；历史联合动作模型的服务、5 步执行前缀、预测／Attention 面板和 LIBERO／Plus 协议见 [历史测评说明](history/joint_evaluation.md)。

Subject 夹爪区域不等于持物身份识别，反事实目标定位不等于错误抓取恢复，视觉误差下降不等于动作专家使用了表征。动作收益需要配对干预与同协议成功率支持。

报告写明数据／模型版本、checkpoint、样本与任务范围、增强、指标定义和异常数量；人工待验收与自动通过分开记录。
